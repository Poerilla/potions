## Rules

- **Monday OR** / Tue–Fri entries / close beyond high/low.
- **R** SL=1R TP=2R. **Size:** 3 — drop **2**@30% DD, cut **1**@50% DD.
- **HTF filter:** skip when last 1h has **both** MA50/150 and OBV×SMA20 opposed.
- **Shifted primary (parallel):** after flat@50%, wait for opposite Mon extreme breakout (failed MonH → short MonL; failed MonL → long MonH) with same 3 / DD / 1R–2R; opposite extreme is reserved for the sidecar (does not block same-side primary re-breaks; does not count toward max primary/week).
- Max **2** primary trades/week. Fee $1.50/unit, PV $100k.
