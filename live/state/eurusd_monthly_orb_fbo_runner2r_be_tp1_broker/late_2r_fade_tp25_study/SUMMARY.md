# Late 2R fade → original TP25 + runner contribution

## 1) Fade the late 2R tag, exit at original TP25

When **TP3 (2R)** hits **at/after half-month**: short the long (or vice versa) at 2R, cover at **original TP25 (0.25R)**. Size **3** (runner size). No intermediate stops — month-end flatten if TP25 not tagged. Next session after 2R.

| Metric | Value |
|---|---:|
| Late 2R hits | 19 (fadeable 16) |
| Fade net (3u) | **$1,227** |
| WR | 50.0% |
| Hit original TP25 | **6.2%** (only 1/16) |
| Month-end exits | 93.8% |
| Avg / med | $77 / $6 |

**Verdict:** Almost never mean-reverts from late 2R all the way back to TP25 (**~6%**). Overlay is roughly flat noise, not an edge.
