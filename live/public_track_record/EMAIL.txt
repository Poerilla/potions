Why it did not size up again before
- Exporter intentionally used a *single* permanent 2× after cum PnL ≥ 2×|full-sample 1× max DD| (lookahead). That blocked further doubles.

New rule (shipped)
- Year 1 = base size (1×)
- Each later year-start: if prior-year sized PnL ≥ 2×|prior-year max DD| (lookback only), permanently step up
- Default step ×2; if |prior DD|×2 > 40% of equity at review → ×1.5 instead
- Never sizes down; ups can repeat indefinitely
